# Ecommerce_Sales-Analysis-PowerBI
## Marketing Analysis
#### 📊 I built an E-Commerce Sales & Marketing Analysis project using SQL, Python and Power BI.

I analyze a Kaggle sample dataset of a fashion store that includes 7 related tables capturing 20,000 website visits, 1,000+ orders, products, customers, campaigns, and ad spend data.

##### Here is what I did:

🔹 Python: cleaned the data (missing values, duplicates, wrong ages)

🔹 SQL: joins, CTEs and window functions to answer business questions

🔹 Power BI: built a 3-page dashboard with DAX measures for revenue, profit, AOV, conversion rate, ROAS and CPA

##### 💡 What I found:

1️⃣ Mobile brings about 70% of traffic, but converts at only 4.2%. Desktop converts at 8.9%. Fewer than half of mobile users who start checkout complete it. This suggests the mobile checkout needs fixing.

2️⃣ Email campaigns gave the best return on ad spend (about 28x). Instagram Reels campaign gave the lowest (3.9x), so it needs a creative and audience review.

3️⃣ Sales peak from September to December. Ads and stock should be planned before this season.

##### ✅ What I learned: a good analysis does not stop at charts. It ends with a clear action for the business.
